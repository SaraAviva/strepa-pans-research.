This is a reconstruction, not a claim of byte identity with the unavailable original `.py` file. Its reconstructed-source checksum and source-PDF checksum are recorded in `../../provenance/source-manifest.json`.

The historical script retains its original fixed workspace path. Use the portable entry point in `../../analysis/annotation_coverage/` for a normal local run. The PDF is preserved as `../../provenance/source-documents/original_2015_hp_analysis_code.pdf` for independent inspection.
